                                        # The-immersion-glove-
![image alt](https://github.com/koray9012/The-immersion-glove-/blob/72c047ab48da321ac08c33a6ff68c4181be0ff50/15502.jpg)
A custom-built DIY wearable wireless glove mouse powered by an ESP32 and an MPU6050 sensor, featuring physical tactile control buttons and real-time haptic feedback integration for Helldivers 2.

## Key Features & Layout
Motion-Controlled Cursor: Smooth spatial tracking using IMU data streamed via Python and Serial communication.

4-Button Pincer Layout: Integrated tactile buttons mapped for:

Left Mouse Button (LMB)

Right Mouse Button (RMB)

Scroll

Movement Freeze (to hold the cursor in place)

In-Game Haptic Telemetry: Dual vibromotors driven by a Python script connected to Helldivers 2 that delivers dynamic physical feedback for:

Weapon recoil

Nearby stratagems

Heavy weapons

Explosions
